# 📋 Student Task Manager Tracker

A collaborative, lightweight web application built with HTML5, CSS3, and modern JavaScript (ES6+). This project demonstrates real-world software engineering practices, pair programming, and advanced Git/GitHub workflows, including feature branching, issue tracking, peer pull request reviews, merge conflict resolution, and semantic release tagging.

---

## 🚀 Features

- **Task Creation & Management:** Easily add new academic tasks with titles and descriptions.
- **Task Completion Toggle:** Mark tasks as completed with real-time visual feedback and strike-through formatting.
- **Dynamic Task Search:** Filter through active and completed tasks in real time using a responsive search bar.
- **Fully Responsive Design:** Optimized layout for desktop, tablet, and mobile viewports ($\le 540\text{px}$).
- **Clean Semantic UI:** Accessible markup structured with HTML5 semantic elements and styled using modern CSS design tokens.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox, CSS Variables, Media Queries), Vanilla JavaScript (ES6+)
- **Version Control:** Git & GitHub
- **Workflow Tools:** GitHub Issues, Pull Requests, Code Reviews, Branch Protection
